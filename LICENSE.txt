The individual files of this project are provided under various licenses, which
are determined according the following rules:

1. If a file named "LICENSE.txt" exists in a subdirectory, then that file
   declares the copyright holder(s) and the license(s) under which all other
   files in that directory and all of its subdirectories (recursively) are
   provided

2. Individual files can declare their own copyright holder(s) and license(s) by
   adding appropriate copyright notices and license texts/identifiers somewhere
   at the top of the file, which overrides the directory license
   (this is the preferred way of declaring licenses)

3. In case it is not possible to declare the license in the file itself
   (e.g. due to it being a binary file or a data file without comment syntax),
   the copyright holder(s) and the license(s) are located in a separate file in
   the same directory and with the same name, but with ".LICENSE.txt" appended
   to the end of it


Instead of a license's full text or a boilerplate text, this project uses
SPDX license identifiers to express which license a given file is provided under.
An SPDX license identifier header takes the form of:

	SPDX-License-Identifier: <SPDX License Expression>

More information can be found at <https://spdx.dev/learn/handling-license-info/>


All other files that are not explicitly provided under a license according to
the above laid out rules are either:

* Too trivial to realistically hold a copyright over its contents, which
  effectively puts them into the public domain
* Verbatim copies with correct attribution found inside, or
* Automatically generated by software, which, unless specifically documented by
  that software, makes their copyright holder and license undefined
